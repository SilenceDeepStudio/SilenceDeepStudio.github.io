VScode的复杂环境构建

首先在vscode中书写C++代码就不是一种非常方便的方式，不光需要我们安装差劲啊，对小白不是很友好，因为安装插件后我们自己需要配置环境和设置，不过本片文章会一步一步讲述这个过程，帮助有一些基础的用户是快速搭建一个完整的C++环境。

C系列的编译器选择复杂性

c语言作为一个及为基础的语言，他的编译器去就是很有学问的选择问题吗，你可以选择gcc、mingw、msvc等，每个都有自己的优势和劣势，根据自己的需求选择合适的编译器。我么介绍连个

mingw编译器

首先我们需要到官网下载mingw编译器，下载地址为：https://mingw-w64.org/ 我们来介绍两个一个是MinGW-w64，一个是LLVM-MinGW。 在左手边选择download https://www.mingw-w64.org/downloads/ 我们就可以看待哦很多预编译工具链，以及他们的packages 向下拖动看到mingw-w64的下载链接 https://github.com/niXman/mingw-builds-binaries/releases 这里面有很多的版本，有其源码的压缩包，也有不同的已经编译过的压缩包，可供我们直接使用，我来解释一下每个版本的区别

  • i686 是32位的编译器，
  • x86_64 是64位的编译器
  • 后面的X.X.X 是版本号，不用过多在意我们直接现在最新版本即可
  • release 是发布版本，我们直接使用即可，不需要我们编译
  • mcf posix win32 指的是你使用这些编译器编译出的可在执行内容需要在什么系统上运行，win32是指在windows系统上运行，posix是指在linux、macos等系统上运行
  • dwarf seh 是调试信息的格式，dwarf是调试信息的标准格式，seh是windows系统的异常处理机制
  • msvcrt ucrt 是C系列的运行时库，如果需要构建的内容c/c++的版本大于11，需要选择ucrt，否则选择msvcrt 以我的例子我的电脑是windows11的系统，并且我希望我的编译后的程序可以在不同系统上运行，那么我需要选择posix，如果我只是在windows系统上运行，那么我选择win32即可。 那么最合适我的就是这个 https://github.com/niXman/mingw-builds-binaries/releases/download/15.2.0-rt_v13-rev1/x86_64-15.2.0-release-posix-seh-ucrt-rt_v13-rev1.7z 下载，并且解压到一个目录下，例如C:\mingw-w64，我们可以看到解压后的目录如下
    C:.
    ├─bin
    ├─etc
    ├─include
    ├─lib
    ├─libexec
    ├─licenses
    ├─opt
    └─x86_64-w64-mingw32

我们只需要关注bin文件下的已经编译好的可执行文件就可以，如果你在vscode在运行的话我们需要在vscode喜爱在c/c++插件，并且打开她的配置文件，配置文件一般情况下是json文件 当然我们有了这个插件后我们可以选择使用ui的方式来配置这个json，不用我们手动进行配置，在vscode的搜索栏中键入shift+>,选择或者输入c/c++: Edit Configuration（ui），即可打开配置文件的ui界面，在此处的

  • Compiler path中输入mingw-w64的bin目录下的gcc.exe文件的路径，例如C:\mingw-w64\bin\g++.exe 选择这个是因为该执行文件同样的可以编译c语言的同时可以编译c++
  • IntelliSense mode此处打开选项可以看到有很多选项，找到windows-gcc-x64 **注意：**你可以把这个路径添加到环境变量的变量中，这样我们就可以在任何目录下直接使用mingw-w64的编译器了!(每个人的环境变量不同且配置过程有危险性这里不做介绍) 这样我们推出这个ui界面就可以看到我们工作目录中自动新添加一个.vscode文件夹，文件夹下有一个json文件，就是我们配置的json文件c_cpp_properties.json 里面的设置就是我们刚才设置的内容，到此为止我们已经可以在vs中直接书写c++或者c语言然后运行
    g++ -o main main.cpp

会看到生成了一个可执行文件main.exe，（此处有一个非常需要注意的问题，就是我们要求我们运行时的目录必须在exe文件下，不然会报错） 如果你想一步直接生成并运行请安装c/c++ runner插件此时直接按下快捷键就可以在控制台中看到输出的效果了

msvc编译器

这个编译器是windows系统的默认编译器，我们可以在windows系统上直接使用，但是我们需要注意的是，这个编译器只能在windows系统上运行，不能在linux、macos等系统上运行。 不过一般情况下如果我们之前并没有编译过这了文件我们是需要安装下载的，下载有一个非常无脑的方式就是安装vs并且安装这一项

  • 使用C++的桌面开发 此时我们就不需要配置环境了，什么都不用操作回到vscode在c/c++插件
  • IntelliSense mode选择windows-msvc-x64即可就可以正常使用预编译了，但是刚才已经说过了这个编译器只能在windows系统上运行，不能在linux、macos等系统上运行， 不过我们可以选择cmake来配置我们的项目，这样我们可以在不同的系统上编译我们的项目。这是另外一个内容了

三方库的安装

作为此系列的语言c++的发展过程无疑是长久的，相对于新兴的语言c#、python等，c++能够找到的包管理器有cmake、conan、vcpkg等。甚至有些管理器已经在历史长河中被淘汰了，我们较为推荐使用vcpkg，因为他是微软推出的较为稳定而且三方包的数量和质量都“硬” 当然这个也很容易就可以安装，首先我们在我们的储存空间进行下载，使用git

    git clone https://github.com/microsoft/vcpkg.git

就可以看到在本文件夹下的vcpkg文件夹了，进入文件夹，双击bootstrap-vcpkg.cmd即可安装vcpkg， 或者你的系统并没有配备显示器，你可以运行

    bootstrap-vcpkg.bat

来安装vcpkg，不论哪一种方式你都可以看到在文件夹下出现了一个vcpkg.exe文件，这就是我们安装的vcpkg， **注意：**你可以选择把他添加到环境变量的变量中，这样我们就可以在任何目录下直接使用vcpkg了!(每个人的环境变量不同且配置过程有危险性这里不做介绍) 此时我们回到vscode中

    vcpkg -v

如果配置成功了，就会看到vcpkg的版本号，否则就会报错

三方库的管理以及以来三方库的项目构建的管理者cmake

camke这也是一种语言，其实并不需要我们专门学习，此教程的受众并不是小白，而是有c++基础的人。因此基板上只要了解依赖关系，如何编译静态库动态库运行可执行文件，就可以在使用的时候慢慢接受了 同样的来到cmake的官网，下载cmake的安装包， https://cmake.org/download/ 下载完成后，双击安装包，按照提示安装即可，一定要添加到环境变量的变量中，一般情况下我们的cmake会在安装时询问！

项目构建

一般情况下我们的cmake项目构建文件是CMakeLists.txt放在我们的main.cpp文件同级目录下，注意这里的文件名称是CMakeLists.txt，不能是其他名称，否则会报错一个字母都不能错 ，来到vscode的插件中搜索cmake，安装cmake插件以及cmake tools插件，因为他较为方便和可视化的让我们对我们的项目进行构建和调试

好了到此为止c系列的环境构建已经完成，我们可以开始书写我们的代码了，但是三方库的引用以及使用我们还需要另外的知识，我们需要放在cmake的教程中详细说明，他较为系统，同时还可以了解项目的构建样式
